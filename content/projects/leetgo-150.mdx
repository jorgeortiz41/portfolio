## Context

Learning a language by reading its documentation teaches you syntax. Learning it
by solving 150 problems that each stress a different data structure teaches you
what the language is actually like to work in — where its standard library is
generous, where its type system gets in the way, and what idiomatic code looks
like when you are not copying a tutorial.

## Approach

Worked through the standard topic coverage — arrays, hashing, two pointers,
sliding window, stacks, binary search, linked lists, trees, tries, backtracking,
graphs, dynamic programming and intervals — in Go rather than in a language I
already knew well, so that the language was as much the subject as the
algorithms.
